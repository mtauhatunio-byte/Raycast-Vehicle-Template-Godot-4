# The Abandoned Hilly Drive

A small 3D vehicle physics project made with **Godot 4**.

Originally was supposed to be a full fledged game, kind of abandoned it and turned it into a template

BTW, I want to mention, there are 2 cars, one that is completely physics and force-driven and one has more arcade physics. 

## Features

Raycast vehicle.
Audio.
TerraBrush.
DebugDraw
TerraBrush
ProjectTimeTraker
Some Unused shaders.


## Controls

W to Accelerate
S to Decelerate
A to Steer Left
D to Steer Right
SPACE to handbrake
SHIFT to drift
R to reload scene


## Built With

**Engine:** Godot 4
**Language:** GDScript
  

## About

The Project is a small prototype of a physics-based RayCast vehicle, not a full complete game.
