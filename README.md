# The Abandoned Hilly Drive

A small 3D vehicle physics project made with **Godot 4**.

Originally was supposed to be a full fledged game, kind of abandoned it and turned it into a template

## Features

Raycast vehicle.
Audio.
TerraBrush.
DebugDraw
TerraBrush
ProjectTimeTraker


## Controls

W to Accelerate
S to Decelerate
A to Steer Left
D to Steer Right
SPACE to handbrake
SHIFT to drift


## Built With

**Engine:** Godot 4
**Language:** GDScript
  

## About

The Project is a small prototype of a physics-based RayCast vehicle, not a full complete game.
